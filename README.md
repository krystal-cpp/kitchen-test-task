# Cozy Kitchen Landing Page

Тестовое задание на вёрстку лендинга кафе «Уютная кухня».

## Стек

- React
- TypeScript
- Vite
- Tailwind CSS
- Swiper

## Features

- Адаптивная вёрстка
- Слайдер галереи
- Аккордеон FAQ
- Форма бронирования
- Модальное окно успешной отправки
- Валидация формы

## Запуск

```bash
npm install
npm run dev
```
